# 02 — Technology Stack

## Application: Talo (single app, three platform targets)

There is only one application in this repository. The stack below applies to Android, Web, and iOS from a single codebase.

| Concern | Technology | Evidence |
|---------|------------|----------|
| Framework | Expo SDK 56 (`expo ~56.0.12`), React Native 0.85.3, React 19.2.3, New Architecture + Hermes | `package.json`, `docs/reports/BUILD_PERFORMANCE_AUDIT.md` |
| Language | TypeScript ~6.0.3, strict mode | `package.json`, `tsconfig.json`, AGENTS.md |
| UI libraries | NativeWind v4 (`className` styling over TailwindCSS 3.4), custom design-system primitives in `src/components/ui/` (19 components), `expo-symbols` (SymbolView icons), `expo-image`, `react-native-country-flag`, `unicode-emoji-json` | `package.json`, `tailwind.config.ts`, `src/components/ui/` |
| State management | Zustand v5 (7 stores; 2 persisted via `zustand/persist` + AsyncStorage) | `src/stores/` |
| Networking | `@supabase/supabase-js` v2 (PostgREST + Realtime WebSocket + Storage + Auth); `react-native-url-polyfill`; no axios/fetch wrapper layer | `src/lib/supabase.ts` |
| Data fetching | **No React Query / TanStack Query** (zero matches in repo). Pattern: service modules (`src/services/*`) call Supabase; hooks orchestrate; Zustand stores hold results | `src/services/`, `src/hooks/` |
| Realtime | Supabase Realtime: `postgres_changes` channels (per-room, global, calls), Presence (typing), Broadcast (WebRTC signaling) | `src/hooks/useRealtime.ts`, `useTypingIndicator.ts`, `src/services/callService.ts` |
| Navigation | Expo Router ~56.2 (file-based, typed routes enabled), native Stack with full-screen swipe-back, route groups `(auth)` / `(tabs)` | `app/`, `app.json` `experiments.typedRoutes` |
| Local storage | `@react-native-async-storage/async-storage` (theme, language, drafts, recent emojis); `expo-secure-store` (Supabase session, app-lock PIN hash, push token, install ID); web falls back to browser storage | `src/lib/supabase.ts`, `src/theme/ThemeProvider.tsx`, `src/stores/draftStore.ts` |
| Animation | `react-native-reanimated` v4.3 + `react-native-worklets`; `react-native-gesture-handler` (swipe-to-reply); `react-native-keyboard-controller` (UI-thread keyboard animation) | `package.json`, `src/components/chat/MessageBubble.tsx` |
| Lists | `@shopify/flash-list` v2 (chat, emoji picker, search, saved messages, blocked users, media) | `src/components/chat/MessageList.tsx` |
| Calls | `react-native-webrtc` v124 + `@config-plugins/react-native-webrtc` + `react-native-incall-manager`; platform-split `src/lib/webrtc.ts` / `webrtc.web.ts` | `package.json`, `src/lib/` |
| i18n | i18next ^26 + react-i18next ^17, `expo-localization` detection, `intl-pluralrules` polyfill, typed keys, en + vi | `src/i18n/` |
| Fonts | `@expo-google-fonts/inter` — per-weight subpath imports (400/500/600/700 only) | `app/_layout.tsx` |
| Push | `expo-notifications` + FCM (via Expo Push API), `expo-device` | `src/services/notificationService.ts` |
| Security features | `expo-local-authentication` (biometric app lock), `expo-crypto` (PIN hashing) | `src/services/appLockService.ts` |
| Analytics | `@vercel/analytics` + `@vercel/speed-insights` (web-only via `.web.tsx` split) | `src/components/VercelInsights.web.tsx` |
| Build tools | Metro bundler (with `withNativeWind`), Babel (`babel-preset-expo` + nativewind), EAS Build (CNG — `android/` regenerated by prebuild), custom config plugin `plugins/withGradleBuildOptimizations.js`, EAS workflow `.eas/workflows/build-android-production.yml` | `metro.config.js`, `babel.config.js`, `eas.json` |
| Testing | **None.** No test runner, no test files, no ESLint, no Prettier, no CI quality gate (confirmed by `PRODUCTION_CHECKLIST.md` §8) | — |
| Shared libraries | Not applicable — no internal packages. Cross-platform sharing via React Native Web + platform-split files (`VercelInsights.web.tsx`, `webrtc.web.ts`, `callAudio.web.ts`, `RemoteVideo.web`, `VideoStream.web`) | `src/` |
