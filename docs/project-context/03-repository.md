## Folder Responsibilities

| Folder | Responsibility |
|--------|----------------|
| `app/` | Route definitions only. Screens compose hooks + components; layout and navigation. One-way data flow starts here: **Screen → Hook → Store/Service → Supabase** (per AGENTS.md). |
| `src/components/` | Presentational UI only — no direct Supabase calls. `ui/` is the design-system contract; `chat/`, `rooms/`, `call/` are feature components. |
| `src/hooks/` | Orchestration layer: bridge screens to stores/services, own realtime subscriptions and their cleanup. |
| `src/stores/` | Zustand client state: message cache, room list, auth session/profile, call session, privacy settings, persisted drafts/emojis. Optimistic updates live here. |
| `src/services/` | The only layer allowed to call `supabase.from()` / `.rpc()` / `.storage`. Plain objects with async methods; `if (error) throw error` convention. Known exception: `authStore` calls `supabase.auth` directly. |
| `src/lib/` | Cross-cutting utilities: the Supabase client singleton, constants (page sizes, timeouts), platform-split WebRTC/audio, receipt math, haptics. |
| `src/types/` | `database.ts` is generated by `supabase gen types` (never hand-edited); `index.ts` exposes domain aliases (`Tables<>`, `InsertTables<>`, `UpdateTables<>`). |
| `supabase/` | Entire backend definition: migrations are the schema source of truth; one edge function; ops runbook. |
| `docs/` | Human documentation: design docs, security review, audits, this snapshot. |
| `locales/` | Translation resources; English keys drive the typed `t()` signature. |
| `scripts/` + `plugins/` | Dev tooling: env switching, brand-asset generation, Gradle build tuning injected at prebuild. |
| `android/` | Generated (Continuous Native Generation); tracked locally for direct Gradle builds, regenerated on every EAS build. |
| `.cursor/` `.agent/` `.qoder/` | Per-IDE mirrors of the modular AI coding rules (8 topic files each, indexed from AGENTS.md). |
| `apps/`, `packages/`, `shared/`, `configs/` | **Not found in repository** — no monorepo layout exists. |
